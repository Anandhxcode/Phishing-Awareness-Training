## 📋 Project Overview

This project is a **Phishing Awareness Training presentation** created as part of my learning during the **CodeAlpha Cybersecurity Internship**.

## 🔑 Key Topics Covered

### Types of Phishing Attacks
- 📧 **Email Phishing** – Fake emails impersonating trusted organizations  
- 📱 **Smishing (SMS)** – Fraudulent text messages  
- 📞 **Vishing (Voice)** – Scam phone calls  
- 🎯 **Spear Phishing** – Targeted individual attacks  
- 🐋 **Whaling** – Attacks aimed at executives and high-value targets  

### Common Red Flags
- ❌ Suspicious or misspelled email domains  
- ❌ Generic greetings like “Dear User”  
- ❌ Urgent or threatening language  
- ❌ Unexpected attachments or links  
- ❌ Requests for passwords or personal information  

---

## 🛡️ Protection Strategies

1. Verify the sender before clicking any links  
2. Type website URLs manually instead of clicking email links  
3. Enable two-factor authentication (2FA)  
4. Keep operating systems and applications updated  
5. Use strong and unique passwords  
6. Report suspicious emails  
7. Stay informed about new phishing techniques
